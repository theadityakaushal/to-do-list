# To-Do List

## Description
A simple To-Do List application built using HTML, CSS, and JavaScript. This app allows users to add tasks, mark them as completed, and delete tasks.

## Features
- Add new tasks to the list.
- Mark tasks as completed (with a strikethrough effect).
- Delete tasks from the list.

## Technologies Used
- **HTML**: For the structure of the application.
- **CSS**: For styling the application.
- **JavaScript**: For adding interactivity.

## How to Use
1. Open the `index.html` file in any modern web browser.
2. Use the input field to type a new task.
3. Click the "Add" button to add the task to the list.
4. Click on a task to mark it as completed.
5. Click the "X" button next to a task to delete it.
